# 大国太空舰队：型号 · 舷号 · 编成规范（草案 A）

> 适用范围：2100 年前后大国太空舰队
> 原则：型号管设计身份，舷号管单舰身份；分型按轨道任务，不按海海军隐喻
> 状态：草案，可随型号落地修订

---

## 1. 命名总则

### 1.1 型号格式

```
系列码-序号代际
```

| 段 | 规则 | 示例 |
|----|------|------|
| 系列码 | 2 个大写拉丁字母，按**任务系列**固定，不按体量临时发明 | `YS` `HW` `QS` |
| 序号 | 两位起（`01`、`02`…），同系列内由小到大、由轻到重 | `01` `02` |
| 代际 | 大写字母；`A` = 第一版设计；重大换代进 `B`、`C` | `A` `B` |

**完整示例：** `YS-01A`、`HW-01A`、`QS-02A`

**改型规则：**

- 推进、主武备、防护或总体布局换代 → 升代际（`01A` → `01B`）
- 仅传感器批次、软件、弹种适配 → 仍用原型号，附录记 `Block II` / 批次号
- 同平台不同任务侧重 → **换序号不换系列**（如 `QS-01A` 通用、`QS-02A` 拦截强化）

### 1.2 型号与舷号必须分开

| | 型号 | 舷号 |
|---|------|------|
| 回答的问题 | 这是哪一种设计 | 这是哪一艘具体船 |
| 何时分配 | 定型时 | 下水/服役入列时 |
| 会否重复 | 同型号可有多艘 | 全舰队唯一 |
| 书写 | `QS-01A` | 四位数字，如 `3107` |

**标准公文写法：**

```text
QS-01A 型多用途驱逐舰，舷号 3107
```

**简报写法：**

```text
驱逐 3107
QS-01A/3107
```

禁止把舷号写进型号字符串（错误示例：`QS-01A-3107` 当作型号）。

### 1.3 体量档（标签，不进型号）

体量只作说明标签，**不占用**系列码或代际字母：

| 档 | 含义（太空口径） |
|----|------------------|
| 微 | 穿梭、驳运、舰载小艇级 |
| 小 | 近防护卫、轻勤务 |
| 中 | 驱逐、标准运输等编队主力数量型 |
| 大 | 巡洋、重运、轻型前进基地 |
| 超 | 远征母舰、破轨主力舰、大型枢纽舰 |

## 2. 系列码总表

### 2.1 主战与区控

| 系列码 | 名称 | 职责一句话 |
|--------|------|------------|
| `HT` | 远征母舰 | 可机动的轨道前进基地：机群、C2、推进剂/弹药中转 |
| `ZJ` | 破轨主力舰 | 交会窗口内砸开加固目标（要塞、对方旗核、大型站） |
| `XJ` | 区控巡洋舰 | 远程传感 + 多层拦截 + 支队指挥 |
| `QS` | 多用途驱逐舰 | 数量最多的轨道工作马：护航、驱离、局部制轨 |
| `HW` | 护卫舰 | 内圈近防、港站与运输队末段；中型可跟战斗编队外圈 |
| `QX` | 隐身潜航舰 | 低可探测渗透、伏击、破交（可选线） |
| `YT` | 攻舰快艇级 | 高机动短窗口突击（可选线） |

### 2.2 体系与支援

| 系列码 | 名称 | 职责一句话 |
|--------|------|------------|
| `YJ` | 预警指挥舰 | 战略级传感与航迹融合，不替代 XJ 的编队拦截 |
| `DZ` | 电子战舰 | 电磁/频谱对抗、致盲与诱骗 |
| `ZX` | 侦察监视舰 | 长期值守与战略侦察 |
| `YS` | 运输舰 | 人员与物资轨道投送（含穿梭） |
| `BY` | 补给舰 | 推进剂、弹药、耗材在轨补给 |
| `WX` | 维修工程舰 | 抢修、拖带、结构作业 |
| `LZ` | 两栖投送舰 | 对表面/设施的投送与回收 |
| `JY` | 救援舰 | 搜救、乘员回收 |
| `JL` | 教练舰 | 训练与科目鉴定 |
| `KY` | 科研试验舰 | 勘探、试验、验证 |

> 撞码规避：预警用 `YJ`，鱼雷/攻舰快艇用 `YT`，二者不要混用。

## 3. 舷号规则

### 3.1 总则

- 舷号为 **4 位十进制数**，全舰队唯一
- 按**任务号段**分配，不按下水年份冒号
- 退役后号段可冷置后再用（政策另定）；现役不得复用

### 3.2 号段分配

| 号段 | 用途 |
|------|------|
| `1xxx` | 远征母舰 `HT` |
| `2xxx` | 护卫及轻型战斗（`HW`，轻型 `QS` 可视编制归入） |
| `3xxx` | 驱逐 `QS`、巡洋 `XJ` |
| `4xxx` | 破轨主力 `ZJ`、隐身 `QX` |
| `5xxx` | 运输 `YS`（已定） |
| `6xxx` | 补给 `BY`、维修 `WX` |
| `7xxx` | 两栖 `LZ`、救援 `JY` |
| `8xxx` | 预警 `YJ`、电战 `DZ`、侦察 `ZX` |
| `9xxx` | 试验、教练 `JL`、科研 `KY` |

### 3.3 型号—舷号关系（示意）

| 型号 | 典型舷号 | 说明 |
|------|----------|------|
| `HT-01A` | `1101`… | 同型多艘，舷号递增 |
| `HW-01A` | `2101`… | 小型护卫，数量多 |
| `QS-01A` | `3101`… | 通用驱逐 |
| `XJ-01A` | `3201`… | 可与 QS 同分 `3xxx`，用百位区分批次政策可选 |
| `ZJ-01A` | `4101`… | 少而精 |
| `YS-01A` | `5101`… | 小型穿梭 |
| `YS-02A` | `5201`… | 运输舰 |

> 同号段内具体百位划分（如 QS 用 `31xx`、XJ 用 `32xx`）由舰籍部门细则规定，本规范只锁定千位任务段。

## 5. 型号关系（谁依赖谁）

```text
                    ┌─────────┐
                    │  YJ/ZX  │  战略传感（可选加强）
                    └────┬────┘
                         │ 航迹/告警
              ┌──────────▼──────────┐
              │        HT          │  远征旗核：机群与前进基地
              └──────────┬──────────┘
           机群开路│      │回收窗口必须被保护
              ┌───▼──┐ ┌─▼───┐
              │  ZJ  │ │ XJ  │  XJ = 传感幕 + 拦截走廊 + 支队指挥
              └───┬──┘ └─┬───┘
                  │破轨   │分配拦截与轨道槽
              ┌───▼──────▼───┐
              │      QS      │  数量型：护航、驱离、补位
              └───────┬──────┘
                      │内圈末段
              ┌───────▼──────┐
              │     HW       │  近防与低烈度值更
              └───────┬──────┘
                      │伴飞但不进交战核心
         ┌────────────┼────────────┐
         ▼            ▼            ▼
       YS           BY           WX
     运输投送     推进剂弹药     抢修拖带
```

**依赖关系摘要：**

| 若缺少… | 后果 |
|---------|------|
| `QS` | 转移走廊护不住，重舰被迫干杂活 |
| `XJ` | 无可靠传感/拦截幕，`HT`/`ZJ` 出远门高危 |
| `HT` | 只有炮舰集群，无持续机群与前进基地 |
| `ZJ` | 打得开骚扰，砸不开要塞级目标 |
| `HW` | `QS` 被末段近防拖死，成本结构恶化 |
| `BY`/`YS` | 远征变成单程票 |

**建造优先级（成形顺序）：**
`QS-01A` → `XJ-01A` → `HT-01A` → `ZJ-01A`，并行补 `HW-02A`、`BY-01A`。

## 6. 职责详表（太空口径）

### 6.1 战场约束（分型依据）

分型依据下列约束，**不是**海面舰种平移：

- Δv 预算与在轨加注
- 散热孔径与热容峰值
- 传感器视距、光时延、行星/太阳遮挡
- 交会窗口与轨道面/相位几何
- 是否搭载可回收子航天器

### 6.2 各系列职责

#### HT 远征母舰

- **主责：** 搭载与回收舰载航天器；深空 C2；推进剂/弹药中转；有限维修
- **不责：** 与 `ZJ` 对射；单独闯入对方拦截走廊
- **位置：** 编队几何中心或阴影侧，由 `XJ`+`QS`+`HW` 保护回收窗口

#### ZJ 破轨主力舰

- **主责：** 在交会窗口对加固目标倾泻决定性火力
- **不责：** 长期哨位；运输线日常护航
- **位置：** 突击段压上，打完立即改轨脱离，减少在残骸区耗 Δv

#### XJ 区控巡洋舰

- **主责：** 远程传感幕、中远程拦截、无 `HT` 时任支队旗核
- **不责：** 替代 `ZJ` 破坚；替代 `QS` 的数量铺开
- **位置：** 传感前出与拦截走廊中段

#### QS 多用途驱逐舰

- **主责：** 护航转移段、驱离轻型威胁、局部制轨、编队补位
- **不责：** 单舰硬刚对面 `ZJ`；充当战略前进基地
- **位置：** 数量最多，分布在护航走廊与拦截幕补位

#### HW 护卫舰

- **主责：** 内圈末段拦截、港站与勤务轨道安全、低烈度巡逻
- **不责：** 破轨；远程区控
- **位置：** 运输队与旗核内圈

#### YS / BY 等支援

- **YS：** 人货投送；交战前与旗核拉开安全距离
- **BY：** 维持编队 Δv 与弹仓；远征必需
- **WX / JY / …：** 按任务挂靠，不进标准打击群最小集

## 7. 标准配比（编成）

配比为**编制基准**，实战可加减；数字指舰级数，不含舰载航天器。

### 7.1 远征打击群（以 HT 为核）

| 型号角色 | 数量 | 说明 |
|----------|------|------|
| `HT-01A` | 1 | 旗核 |
| `XJ-01A` | 2 | 传感/拦截双轴 |
| `ZJ-01A` | 1～2 | 视目标硬度 |
| `QS`（以 01A 为主） | 4～6 | 护航与补位 |
| `HW-02A`（或 01A 加强） | 2～4 | 内圈 |
| `BY` / `YS` | 按航程 | 交战前拉开 |

**用途：** 夺拉格朗日点或打击对方枢纽；机群开路 → `ZJ` 破轨 → `XJ` 保回收窗口。

**数量感：** 同型 `QS` ≫ `XJ` ≫ `ZJ`；`HT` 个位数。

### 7.2 轨道巡控支队（无母舰）

| 型号角色 | 数量 |
|----------|------|
| `XJ-01A` 或 `XJ-02A` | 1（支队旗） |
| `QS` | 3～4 |
| `HW` | 2 |

**用途：** 日常慑控、走廊护航、反骚扰；靠传感优势，不靠破轨。

### 7.3 破轨突击群

| 型号角色 | 数量 |
|----------|------|
| `ZJ` | 2 |
| `XJ-01A` | 1（专护突击段） |
| `QS` | 2～3 |

可选短时借用 `HT` 机群做第一波诱饵/致盲，突击结束后立即脱离。

**用途：** 短窗口高烈度，不恋战。

### 7.4 运输护航队（后勤）

| 型号角色 | 数量 |
|----------|------|
| `YS`（任务舰） | 按货运 |
| `QS` 或 `HW-02A` | 2～4 |
| `HW-01A` | 按末段加强 |

**用途：** 保证转移段生存，不主动寻战。

### 7.5 常备规模比例（参考）

一支「能打大仗」的常备力量，舰级比例大致：

| 系列 | 相对比例（约） |
|------|----------------|
| `QS` | 1.0（基准最多） |
| `HW` | 0.6～1.0 |
| `XJ` | 0.25～0.35 |
| `ZJ` | 0.1～0.15 |
| `HT` | 0.05～0.1 |
| `YS`+`BY` | 视远征强度，通常不低于主战舰总数的 1/3 当量 |

## 8. 书写与口令规范

| 场景 | 写法 |
|------|------|
| 定型文件 | `QS-01A 型多用途驱逐舰` |
| 舰籍 | `舷号 3107` |
| 联写 | `QS-01A「弦月」舰，舷号 3107` |
| 编队口令 | `巡控一支队，旗核巡洋 3201` |
| 禁止 | 型号内嵌舷号；海战口令硬套（左舷阵、反潜警戒等） |

太空编队口令优先使用：**旗核、传感前出、拦截走廊、突击段、伴飞相位、高低轨分层**。
